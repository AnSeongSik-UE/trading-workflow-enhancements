# trading-workflow-enhancements

기존 Python·PyQt 주식 자동매매 프로그램에서 맡았던 거래내역 조회·표시와 손절·익절 처리 작업을 비식별 예시로 재구성했습니다. 이 저장소의 코드는 당시 운영 소스나 완성된 자동매매 프로그램이 아닙니다.

## 처리 흐름

`조회 기간 선택 → 거래내역 요청 → 금액 변환·합계·표시 데이터 구성`

`보유 수량·수익률 확인 → 손절·익절 기준 비교 → 매도 의도 반환`

## 기술

- 원래 작업 환경: Python, PyQt, 증권사 Open API
- 공개 예시: Python 표준 라이브러리와 고정 예시 데이터

## 개인 기여

- 거래내역 조회 기간의 기본값과 표 정렬을 설정했습니다.
- 일별 실현손익 조회 요청과 응답의 금액·수수료·세금 데이터를 화면에 표시하도록 처리했습니다.
- 수익률을 선택한 손절·익절 기준과 비교해 매도 흐름으로 연결하는 로직을 추가했습니다.

## 협업 범위

기존 자동매매 프로그램의 기본 코드와 전자책 자료는 외부에서 제공된 것입니다. 위 개인 기여는 원본 코드에 작업 표시가 있는 기능 범위만 설명합니다. 프로그램 전체의 설계나 기존 매수·주문·계좌 기능을 개인 구현으로 주장하지 않습니다.
